High-Performance ASCII Background Animator

Zero-dependency Canvas 2D background rendering engine for web applications, splash pages, and technical documentation. Features dense & sparse matrix math, photographic image sampling, multi-stop gradient color blending, and GPU-safe auto-pausing.

$ npm install @staticcanvas/asciiam v1.0.0
Architectural Highlights & Features

Rendering Algorithms & Math

Supports full matrix scanning and sparse particle loops. Dense algorithms visit every cell in the grid per frame; sparse algorithms skip inactive cells to maximize 60fps power efficiency.

wave current ripple fadeIn matrix snow sparkle customCell(api)

Photographic Image Sampling

Sample any photographic or vector graphic into character density maps. Features FOV viewport zoom, image scaling, pixel color extraction, and dynamic character set re-sampling.

PNG/JPEG/WebP/SVG imageScale imageFov colorFromImage waveSweep radialRipple scanlinePass thermalNoise

Multi-Stop Gradients & Color

Single-pass color synthesis supporting 1–6 gradient stop colors, linear, radial, and cubic blending equations, smooth angle rotation, animated hue shifts, and color breathing dynamics.

1-6 Stops Linear/Radial/Cubic hueRotate breathe Animate Angle

Motion Dynamics & Cursor Glow

Control animation frame rate, edge vignette fading, frame-blend motion trails, sine pulse expansion, and real-time interactive mouse cursor glow radius.

speed edgeFade trail pulse cursor.radius cursor.strength

Power Optimization & Lifecycle

Automatically pauses execution when offscreen via IntersectionObserver or when the browser tab is hidden. Font rendering uses quantized level caching with zero DOM reflows.

IntersectionObserver PageVisibility API Quantized Cache Zero Dependencies Reduced Motion

Module Integration & API

Packaged as ESM and UMD builds. Easily initialize onto any container, mount responsive listeners, and dynamically tweak options at runtime.

ESM / UMD new asciiam('#target', opts) start() / stop() setOption(key, val) destroy()
