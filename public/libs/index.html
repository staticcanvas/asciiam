High-Performance ASCII Background Animator

Zero-dependency Canvas 2D background rendering engine for web applications, splash pages, and technical documentation. Features dense & sparse matrix math, photographic image sampling, multi-stop gradient color blending, and GPU-safe auto-pausing.

$ npm install @staticcanvas/asciiam v1.0.0

Usage and export formats

Choose the package entry for a bundler, native ESM for module scripts, or UMD for a classic script tag. Readable and minified browser bundles expose the same API.

Package ESM

import asciiam from '@staticcanvas/asciiam';

const anim = new asciiam('#hero', asciiam.presets.heroWave);
anim.start();

Browser ESM

<script type="module">
  import asciiam from './libs/asciiam.esm.min.js';
  new asciiam('#hero', asciiam.presets.heroWave).start();
</script>

Classic script / UMD

<script src="./libs/asciiam.min.js"></script>
<script>
  new asciiam('#hero', asciiam.presets.heroWave).start();
</script>

Architectural Highlights & Features

Rendering Algorithms & Math

Supports full matrix scanning and sparse particle loops. Dense algorithms visit every cell in the grid per frame; sparse algorithms skip inactive cells to maximize 60fps power efficiency.

wave current ripple vortex plasma fadeIn fadeOut matrix snow sparkle customCell(api)

Photographic Image Sampling

Sample any photographic or vector graphic into character density maps. Features FOV viewport zoom, image scaling, pixel color extraction, and dynamic character set re-sampling.

Multi-Stop Gradients & Color

Single-pass color synthesis supporting 1–6 gradient stop colors, linear, radial, and cubic blending equations, smooth angle rotation, animated hue shifts, and color breathing dynamics.

Motion Dynamics & Cursor Glow

Control animation frame rate, edge vignette fading, frame-blend motion trails, sine pulse expansion, and real-time interactive mouse cursor glow radius.

Power Optimization & Lifecycle

Automatically pauses execution when offscreen via IntersectionObserver or when the browser tab is hidden. Font rendering uses quantized level caching with zero DOM reflows.

Working with the demo

1. Configure

  1. Start with a named preset or select a rendering mode.
  2. Choose quality, character density, spatial origin, color, motion, and backdrop settings.
  3. Use Image to upload a browser-local file or select an included asset from public/assets/images.

2. Preview and validate

  • Switch between Background, Hero card, and Splash page to inspect contrast and content interference.
  • Enable FPS to compare quality tiers and cell counts.
  • Use Undo and Redo while testing combinations; Reset restores demo defaults without deleting saved presets.

3. Integrate

  • Open Code for a configuration generated from the current controls.
  • Install the package or load the UMD bundle, construct an instance, then call start().
  • Call destroy() when removing a mounted instance so observers and event subscriptions are released.

Operational notes

Lifecycle and accessibility

  • The target must have measurable width and height before construction.
  • Rendering pauses when off-screen or when the document is hidden and resumes without accumulating elapsed time.
  • Reduced-motion preferences are honored by default; toolbar controls use native semantics and keyboard navigation.

Images and local defaults

  • The bundled library is generated from supported files in public/assets/images.
  • After adding PNG, JPEG, GIF, WebP, AVIF, or SVG files, run npm run prepare:bg; development and production builds run it automatically.
  • Uploaded files remain browser-local and use temporary object URLs that are revoked after decoding.

Storage and cleanup

  • Demo options and named presets use versioned local storage and do not leave the browser.
  • Uploaded files use temporary object URLs that are revoked after image decoding.
  • Call the unsubscribe function returned by on(), or call destroy() to clear every subscription at once.
