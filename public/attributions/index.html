Attributions and external resources

Source, license, and service references for icons, demonstration media, future mesh research, registries, and delivery infrastructure.

This page identifies third-party material and external services referenced by the repository; it does not change the MIT license applied to asciiam source code.

Embedded icon paths

The documentation navigation embeds a local subset of Lucide SVG paths. Lucide is distributed under the ISC License, and some Lucide designs derive from Feather under the MIT License. The redistributed notices are preserved in THIRD_PARTY_NOTICES.md.

Icons are embedded locally so documentation navigation does not depend on a client-side icon package or third-party request.

Bundled SVG demonstration asset

docs/static/webutil/assets/images/bird-silhouette.svg is the Bird Shape vector from SVG Repo. SVG Repo identifies that asset as CC0. The file remains a demonstration input for silhouette-aware image-to-ASCII conversion.

Map reference

docs/static/webutil/assets/images/earth-landmask-256-slow.gif uses a globe land-mask source associated with PAT, the free, open-source portable atlas. PAT states that its maps and generating scripts are public domain.

Demonstration photographs

The image library contains development and rendering-test media sourced from Pexels, Pixabay, and local repository contributions. Provider and creator identifiers are retained in filenames where available. Provider references are not blanket license claims: verify an individual source record before redistributing an asset outside this repository.

3D model sources and format references

asciiam bundles no third-party 3D models. Its dependency-free glTF/GLB loader uses the following format and candidate asset sources:

  • Poly Haven models are published under Poly Haven’s CC0 asset license. Record the exact model source and metadata before including one in a demonstration or test fixture.
  • Khronos glTF Sample Assets provide format test cases and example models. Each model carries its own license and credit record; check the selected model directory before use or redistribution.
  • The glTF 2.0 specification defines the core glTF/GLB input boundary. Base-format parsing ships in the main package without external dependencies. Assets requiring Draco, Meshopt, or another compression extension will be rejected. Codec evaluation is deferred research and no decoder or decoder hook is planned for the released runtime.

These references do not grant a blanket license for assets obtained elsewhere.

External project services

GitLab and GitHub host source mirrors and page editing. npm and JSR are package registries. jsDelivr and unpkg provide package CDN delivery after publication. Shields.io supplies README badges. These services are not runtime dependencies of the asciiam library.
