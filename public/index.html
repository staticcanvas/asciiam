ASCII animation engine · v0.10.0

Render animated
ASCII media

asciiam converts procedural fields and sampled images into animated glyph grids. Select WebGL2 or Canvas 2D, compose ordered sequences, and transfer presets between the gallery and web utility.

001 — Runtime

One animation state,
two presentation backends.

Animation modes, sequences, glyph selection, and image masks share one public API. WebGL2 batches visible glyphs into an instanced draw. Canvas 2D remains available for explicit CPU rendering and automatic fallback.

Quick start

app.js
import asciiam from '@staticcanvas/asciiam';

const animation = new asciiam('#hero', {
  ...asciiam.presets.heroWave,
  renderer: 'auto'
});

animation.start();
