      About layers

      Each layer runs its own mode and paints in order (first = bottom) using the toolbar's global settings, blended by opacity and blend mode. A layer's option overrides (JSON) apply only during that layer's own draw pass, then revert — use them to give one layer its own charSet, speed, color, density, and similar fields without changing the others.

      ASCII media renderer

      Dependency-free renderer for procedural ASCII animation, sampled images, and 3D meshes. The default renderer requests WebGL2 and falls back to Canvas 2D. Running instances share one frame scheduler and pause when off-screen where browser observers are available.

      $ npm install @staticcanvas/asciiam npm
      Documentation Preset gallery API reference Changelog

      Product overview

      GPU-first renderer

      WebGL2 batches glyph instances when available. Canvas 2D remains the explicit CPU renderer and automatic fallback.

      ASCII media & compositions

      Procedural fields, sampled images, and 3D meshes render as glyph grids for backgrounds, bounded hero cards, and splash compositions. Images and 3D meshes can be combined into textured 3D ASCII compositions.

      Lifecycle

      Instances share frame scheduling, pause when hidden or off-screen, and expose cleanup through destroy().
