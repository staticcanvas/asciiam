Feature overview

Capabilities

The engine, package outputs, and browser utility cover the following development paths.

Render

GPU and CPU backends

WebGL2 instanced glyph rendering with automatic or explicit Canvas 2D fallback.

Compose

{{ hugo.Data.presets.builtInModeCount }} built-in modes

Fields, reveals, particles, pointer interactions, sampled images, meshes, and custom callbacks.

Sequence

Ordered playback

Per-step delays, durations, repeat rules, transitions, media sources, callbacks, and lifecycle events.

Images

Image-to-ASCII sampling

Cover and contain fitting, animation masks, source color, luminance mapping, RGB ranges, rotation, and mirroring.

3D

Meshes and glTF/GLB

Procedural primitives, typed-array geometry, model loading, transforms, camera controls, and raster styles.

Style

Glyph and color systems

Character sets, spatial alignment, multi-stop gradients, animated color, backdrops, trails, pulse, and edge fade.

Runtime

Shared scheduling

Visibility pausing, reduced-motion handling, quality tiers, resolution scaling, renderer diagnostics, and caches.

Utility

Browser authoring

Presets, live controls, undo and redo, media upload, layout previews, sequence editing, and code generation.

Package

Multiple output formats

Typed ESM and CommonJS package entries plus readable and minified browser ESM and UMD bundles.

Live Gallery

Animation Showcase

Eight live procedural, media-sampled, multi-pass, and 3D compositions rendering in real-time.
