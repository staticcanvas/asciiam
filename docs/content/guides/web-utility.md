The web utility is an authoring surface for asciiam option objects; detailed runtime behavior remains defined by the package API.

## Configure a composition

Start with a preset or animation mode, then adjust renderer, quality, character density, spatial origin, motion, color, backdrop, and image controls. Undo and Redo operate on the current browser session. Reset restores utility defaults without deleting named presets.

The controls are grouped by frequency. Renderer, quality, mode, preset, and output belong to the primary workflow. Image sampling, gradient stops, mask ranges, sequences, diagnostics, and persistence controls are advanced configuration.

## Preview presentation types

Background, Hero card, and Splash page are presentation previews rather than HTML overlays generated by asciiam. Each preview gives the renderer a bounded target and places ordinary interface content beside or above it.

Hero and Splash can use an uploaded or included image as the ASCII source. The image is sampled into glyph density and optional sampled color; the original bitmap is not placed over the preview. Use `cover` or `contain`, image scale, field of view, the global animation mode, and an optional inclusive RGB animation range to control the result.

| Preview | Purpose | Runtime implication |
| --- | --- | --- |
| Background | Evaluate a full-stage ASCII surface behind application content. | One target sized to the stage. |
| Hero card | Evaluate ASCII image or procedural media inside a bounded content card. | One renderer attached to the card media region. |
| Splash page | Evaluate a larger introductory composition and transition sequence. | One renderer attached to the splash media region. |

## Validate performance

Choose `auto` to request WebGL2 first and retain Canvas 2D fallback. Enable the FPS panel to inspect the resolved backend, frame rate, cell count, and quality tier. Test the composition at the actual target size because density, DPR, glyph count, and image sampling work change with dimensions.

For grids and galleries, construct only visible previews and destroy instances that leave the working set. All running instances share a frame scheduler, but each WebGL2 context and glyph buffer still consumes browser resources.

## Export and integrate

Open Code to generate a constructor option object from the current controls. Install the package or select a browser bundle, create an instance after its target has measurable dimensions, then call `start()`.

`app.js`

```js
import asciiam from '@staticcanvas/asciiam';

const animation = new asciiam('#hero-media', {
  ...asciiam.presets.heroWave,
  renderer: 'auto'
});

animation.start();
```

Call `destroy()` when removing the target. This releases observers, subscriptions, presentation resources, and an owned canvas.

## Persistence and local data

| Data | Persistence |
| --- | --- |
| Utility options | Stored in versioned browser local storage. |
| Named presets | Stored locally in the current browser. |
| Undo and redo history | Retained for the current page session. |
| Uploaded images | Browser-local object URLs; not restored on the next visit. |
| Included image manifest | Generated from `public/assets/images` by `npm run prepare:bg`. |
| Generated code | Derived from current state and not stored separately. |

## API reference

| Utility control | Runtime option or API | Default behavior |
| --- | --- | --- |
| Renderer | `renderer`, `setRenderer()` | `auto`; WebGL2 first, Canvas 2D fallback. |
| Quality | `quality`, `maxDPR`, `targetFPS` | Uses the selected quality tier. |
| Mode | `mode`, `setMode()` | Selects the active cell algorithm. |
| Motion and Align | `speed`, `edgeFade`, `trail`, `pulse`, `align` | Updates animation and spatial state. |
| Color and Backdrop | `color`, `gradient`, `backdrop` | Configures glyph and independent backdrop presentation. |
| Image | `setImage()`, image options | Samples a local or remote image into the glyph grid. |
| Sequence | `setSequence()`, sequence methods | Configures ordered animation steps. |
| Code | constructor options | Serializes the current supported configuration. |

The Image popover exposes centered uniform, horizontal, and vertical scaling; field of view; silhouette-aware luminance mapping; animated-image playback and sample rate; sampled color; and an optional RGB animation range. The global Mode popover remains the animation selector after an image is loaded.
