The web utility is an authoring surface for asciiam option objects; detailed runtime behavior remains defined by the package API.

## Configure a composition

Start with a preset or animation mode, then adjust renderer, quality, character density, spatial origin, motion, color, backdrop, and image controls. Undo and Redo operate on the current browser session. Reset restores utility defaults without deleting named presets.

The Character set control includes the documented `asciiExtended` default, ordered density ramps, symbolic palettes, and a custom string editor. Hover Zone and Click Zone expose radius and click-duration controls in Motion. Align provides nine spatial anchors.

The dock keeps Preset, Sequence, Mode, Character set, Motion, Align, Color, Backdrop,
Reset, Image, 3D, and Code directly available. Advanced contains lower-frequency
quality, theme, and history controls. Reset intentionally remains outside Advanced.
Documentation, About, and the FPS switch form one level action row on the stage.

Quality includes a Grid resolution slider. `100%` retains automatic grid measurement;
`50%` reduces cell count for constrained devices, while values up to `200%` increase
logical detail. The live status reports the resulting columns and rows. This setting
changes glyph-grid resolution, not canvas DPR.

The sequence editor is a horizontally ordered node flow. Each node edits its animation,
image-source action, duration, stagger, repeat policy, transition, and JSON option
overrides. Nodes can retain or clear the current image, or load an included image;
reordering changes playback order immediately.

## Preview presentation types

Background, Hero card, and Splash page are presentation previews rather than HTML overlays generated by asciiam. Each preview gives the renderer a bounded target and places ordinary interface content beside or above it.

Hero and Splash can use an uploaded or included image as the ASCII source. The image is sampled into glyph density and optional sampled color; the original bitmap is not placed over the preview. Use `cover` or `contain`, image scale, field of view, the global animation mode, and an optional inclusive RGB animation range to control the result.

| Preview | Purpose | Runtime implication |
| --- | --- | --- |
| Background | Evaluate a full-stage ASCII surface behind application content. | One target sized to the stage. |
| Hero card | Evaluate ASCII image or procedural media inside a bounded content card. | One renderer attached to the card media region. |
| Splash page | Evaluate a larger introductory composition and transition sequence. | One renderer attached to the splash media region. |

## Validate performance

Choose `auto` to request WebGL2 first and retain Canvas 2D fallback. Enable FPS for the
existing compact frame-rate, grid, and drawn-cell line. Enable Extended diagnostics in
Quality for estimated display cadence, CPU-side frame work, fill-history text charts,
renderer details, and active 3D geometry counts. The extended path is off by default and
automatically enables FPS because it owns no independent update loop. Test the composition
at the actual target size because density, DPR, glyph count, and image sampling work change
with dimensions.

For grids and galleries, construct only visible previews and destroy instances that leave the working set. All running instances share a frame scheduler, but each WebGL2 context and glyph buffer still consumes browser resources.

## Export and integrate

Open Code to generate a constructor option object from the current controls. Install the package or select a browser bundle, create an instance after its target has measurable dimensions, then call `start()`.

`app.js`

```js
import asciiam from '@staticcanvas/asciiam';

const animation = new asciiam('#hero-media', {
  ...asciiam.presets.heroWave,
  renderer: 'auto'
});

animation.start();
```

Call `destroy()` when removing the target. This releases observers, subscriptions, presentation resources, and an owned canvas.

The [Usage examples]({{< relref "/examples" >}}) workbench provides a second authoring path. Its **View in web utility** action sends the current JSON-safe options through a base64url-encoded `config` query value. The utility applies that configuration after defaults and locally restored settings, then exposes it as a custom composition. Invalid or non-object values are ignored.

## Persistence and local data

| Data | Persistence |
| --- | --- |
| Utility options | Stored in versioned browser local storage. |
| Named presets | Stored locally in the current browser. |
| Undo and redo history | Retained for the current page session. |
| Uploaded images | Browser-local object URLs; not restored on the next visit. |
| Included image manifest | Generated from `docs/static/webutil/assets/images` by `npm run prepare:bg`. |
| Generated code | Derived from current state and not stored separately. |

## API reference

| Utility control | Runtime option or API | Default behavior |
| --- | --- | --- |
| Renderer | `renderer`, `setRenderer()` | `auto`; WebGL2 first, Canvas 2D fallback. |
| Quality | `quality`, `resolutionScale`, `maxDPR`, `targetFPS` | Uses the selected quality tier and 100% logical resolution. |
| Extended diagnostics | `showStats`, `extendedStats`, `getStats()` | Disabled; samples only when explicitly enabled. |
| Mode | `mode`, `setMode()` | Selects the active cell algorithm. |
| Motion and Align | `speed`, `edgeFade`, `trail`, `pulse`, `align` | Updates animation and spatial state. |
| Color and Backdrop | `color`, `gradient`, `backdrop` | Configures glyph and independent backdrop presentation. |
| Image | `setImage()`, image options | Samples a local or remote image into the glyph grid. |
| 3D | `setModel()`, `meshTransform`, `meshCamera`, rotation options | Uploads local GLB, loads remote glTF/GLB, and controls geometry scale, FOV, and rotation. |
| Sequence | `setSequence()`, sequence methods | Configures ordered animation steps. |
| Code | constructor options | Serializes the current supported configuration. |
| `config` URL value | JSON-safe constructor options | Imports a documentation example without depending on npm or a CDN. |

Backdrop placement is explicit. `behind` draws before glyphs. `over` composites after glyphs, so opacity `1` fully covers the animation. The range and exact numeric input both accept the inclusive interval from `0` through `1`.

The Image popover exposes centered uniform, horizontal, and vertical scaling; field of view; silhouette-aware luminance mapping; animated-image playback and sample rate; sampled color; and an optional RGB animation range. The global Mode popover remains the animation selector after an image is loaded.

The 3D popover accepts local `.glb` files. Its remote URL field accepts `.gltf` or
`.glb`; relative `.bin` references are resolved from a remote `.gltf` URL and require
CORS access. Uniform and axis scale, camera FOV, auto-rotation, and Y rotation speed
are exported in generated configuration.
Rotation and flip controls follow the same ownership rule: image controls transform
the sampled source, while the 3D controls transform both procedural primitives and
imported models through `meshTransform`.

`npm run prepare:bg` generates static 320×180 WebP menu previews when ImageMagick is available. GIF previews use the first frame and image orientation is normalized during generation. Opening the Image popover therefore decodes bounded static previews, not full-resolution sources or animated GIF streams. An original asset is loaded only after its card is selected.
